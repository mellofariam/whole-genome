# Source code for Mello, M.F. et al., 2025. Reconfiguration Timescales for Chromatin Architecture

## Input preparation

The list of the loop anchors and subcompartment annotations for GM12878 is available under GEO accession number [GSE63525](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE63525).


## Coordinate Files
Sample coordinates are available at [https://ndb.rice.edu/Data](https://ndb.rice.edu/Data), under the following entries:
- `Mello_etal_2025_GM12878_500-frames`: light-weight trajectory with 500 frames. Total simulated time of $5 \times 10^5 \tau$, sampling every $10^3 \tau$. Trajectory from the set of 400 replicas used in the structural analyses.
- `Mello_etal_2025_GM12878_50k-frames`: heavy trajectory with 50k frames. Total simulated time of $5 \times 10^5 \tau$, sampling every $10 \tau$. Trajectory from the set of 20 replicas used in the dynamics analyses.

Representative frames can be visualized at [https://ndb.rice.edu/Visual](https://ndb.rice.edu/Visual) under `GM12878-Mello2025` cell line.
